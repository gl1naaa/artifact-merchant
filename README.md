# Artifact Merchant

Терминальная игра о торговце магическими артефактами.

Игрок покупает неизвестные реликвии, исследует их свойства, управляет проклятиями и продаёт предметы покупателям с разными интересами. Главная механика — принимать торговые решения при неполной информации.

## Концепция

- полностью клавиатурный terminal-first интерфейс;
- оценка артефактов с раскрываемыми свойствами;
- подделки, проклятия и опасное хранение;
- динамический спрос и разные типы покупателей;
- репутация и фракции;
- JSON-сохранения с версиями;
- воспроизводимые игровые seed для отладки.

## MVP

1. Новый запуск и пятидневный игровой цикл.
2. Покупка и продажа артефактов.
3. Неполная идентификация и подделки.
4. Базовые проклятия.
5. Сохранение/загрузка в JSON.
6. Rich-интерфейс без мыши.

## Запуск

Требуется Python 3.11+.

```bash
python -m pip install -e .
python -m artifact_merchant
```

Проект находится на стадии проектирования; код будет добавляться вертикальными срезами.

## Структура

- `src/artifact_merchant/domain` — игровые правила;
- `src/artifact_merchant/application` — игровые сценарии;
- `src/artifact_merchant/tui` — терминальный интерфейс;
- `src/artifact_merchant/infrastructure` — сохранения и загрузка контента;
- `docs/` — дизайн и формат сохранений;
- `tests/` — тесты.
