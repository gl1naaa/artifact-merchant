# Game design

## Core loop

Morning events -> buy from suppliers -> inspect/research -> serve customers -> manage curses -> close day -> night consequences.

## Design principles

- Information is valuable but never free.
- Curses create decisions, not arbitrary punishment.
- Prices depend on demand, authenticity, condition and revealed properties.
- Every important result is shown in the event log.
- All actions work from the keyboard; no mouse is required.

## Initial content

The first vertical slice uses three categories: relics, charms and alchemical vessels. It includes one supplier, three customer archetypes, two curses and a five-day run.
